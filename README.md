# alGorithms

A workspace to manually learn algorithm implementations.

Doing this because I believe in first-principles and understanding fundamentals, regardless of AI agents.

An algorithm is done only when both boxes are checked:
`go test ./<module> -run <Name> -v` must pass for correctness and complexity.
